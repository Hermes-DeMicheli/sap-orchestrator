# ABAP Cloud

Business logic executors for ABAP Cloud (RAP, Clean ABAP).

## Structure

- behavior/ -- Behavior definitions and pool implementations
- cds-views/ -- CDS views for projections and interfaces
- clean-abap/ -- AMDP, exception classes, EML examples

## Convention

RAP naming: ZR_ (root BO), ZC_ (projection), ZI_ (interface), ZBP_ (behavior pool).
Clean Core Level A only.
